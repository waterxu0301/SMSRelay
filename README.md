# SMSRelay — Mac SMS 接力工具

读取 macOS Messages 数据库（`chat.db`），提取验证码短信，推送到飞书 / 钉钉 / 企业微信群机器人与邮箱。

**当前版本：1.0.0**

---

## 特性

| 能力 | 说明 |
|---|---|
| 验证码提取 | 6 位数字验证码（左右不紧邻其他数字；多码取**最后一个**） |
| 推送渠道 | 飞书、钉钉、企业微信群机器人 + SMTP 邮件（4 通道） |
| 原文透传 | 推送内容为「标头 + 短信原文」直连，验证码唯一来源为原文，不重复输出 |
| 过滤 | 发件方白名单、关键词白名单、免打扰（静默）时段 |
| 时效控制 | 验证码有效期（默认 300 秒）可配置，过期自动跳过 |
| 可靠性 | 核心子进程崩溃自动拉起；IPC 读写线程自愈；轮询线程异常不静默死亡 |
| 隐私 | 短信原文与验证码**仅在内存流转**，不写入任何数据库与日志 |
| 凭据安全 | 钉钉加签 secret 与 SMTP 授权码存于 macOS 钥匙串，不落盘明文 |

## 快速开始

### 1. 前置条件

| 项 | 要求 |
|---|---|
| 系统 | macOS 13.0 或更高（Apple Silicon / Intel 均可） |
| 短信接力 | iPhone 设置 → 信息 → 短信转发 → 选择此 Mac |
| 机器人 | 至少一个群机器人的 Webhook 地址（飞书 / 钉钉 / 企微） |

### 2. 安装

1. 下载 `SMSRelay-1.0.0.zip` 并解压；
2. 将 `SMSRelay.app` 拖入「应用程序」文件夹（`/Applications`）；
3. **右键 → 打开**（ad-hoc 签名未公证，Gatekeeper 首次需手动放行）；
4. 启动后在「偏好设置 → 投递目标」中添加 Webhook 地址；
5. 点击「开始监听」。

### 3. 授予完全磁盘访问权限（必需）

macOS 保护 `~/Library/Messages/chat.db`，应用必须获得「完全磁盘访问权限」才能读取：

1. 打开 **系统设置 → 隐私与安全性 → 完全磁盘访问权限**；
2. 点击 `+`，添加 `/Applications/SMSRelay.app`；
3. **完全退出并重新启动**应用（授权在进程启动时生效）。

> 授权后若日志流出现 `SCAN_FAIL`，说明权限未生效或授权给了其他副本 —— 请确认添加的是 `/Applications` 下的那份，并重启应用。
>
> 提示：每次重新构建（ad-hoc 重新签名）后，系统可能需要重新授权。

### 4. 开始使用

| 页签 | 用途 |
|---|---|
| 投递目标 | 增删改查群机器人 / 邮箱通道；启用停用；测试推送预览 |
| 邮件通道 | 配置 SMTP 与授权码 |
| 过滤与免打扰 | 发件方 / 关键词白名单、静默时段、轮询间隔、有效期 |
| 投递统计 | 最近 7 天投递成功率（目标 ≥ 99.5%） |
| 日志流 | 实时运行日志；导出近 7 天日志 |
| 告警记录 | 全目标投递失败等告警 |
| 调试动作 | 立即扫描一次、刷新内存缓冲、手动重推 |

## 推送格式

推送内容为「标头 + 短信原文」直连的**单行**：

```
【SMS接力】由数字化监控平台发送，验证码：583980，有效期为120秒，发送时间2026-10-30 10:06:39
```

- 标头 `【SMS接力】` 表明消息由本程序自动转发；
- 原文**逐字完整保留**（发送方说明、验证码、有效期、时间戳等），不做任何删减改写；
- **验证码全文只出现一次** —— 下游取码程序按「首个 6 位数字」「末个 6 位数字」或「`验证码[:：]` 后的数字」解析，结果一致。

无原文的路径（测试推送、手动重推）推送为 `【SMS接力】验证码 000000`。

## 隐私说明

- 只读取正文含「验证码」的短信，其余消息不读取、不处理；
- **短信原文与验证码不落库**：`app.db` 与所有日志中均不含短信正文与验证码；
- 环形缓冲（最近 100 条，供手动重推）仅存验证码与指纹，不存原文；
- 敏感凭据（钉钉加签 secret、SMTP 授权码）存放于 macOS 钥匙串，IPC 通道只传递尾 4 位提示；
- Webhook 地址在界面中打码显示。

## 从源码构建

```bash
cd src
python3.13 -m venv .venv-pack
.venv-pack/bin/pip install py2app \
    pyobjc-framework-Cocoa \
    pyobjc-framework-UserNotifications \
    pyobjc-framework-ServiceManagement

.venv-pack/bin/python setup.py py2app          # 产物：dist/SMSRelay.app
codesign --force --deep -s - dist/SMSRelay.app  # ad-hoc 签名
cd dist && ditto -c -k --keepParent SMSRelay.app ../SMSRelay-1.0.0.zip
```

构建环境：macOS 26+ / arm64、Python 3.13.15、py2app 0.28.10、PyObjC 12.2.2。

> 若需免 Gatekeeper 引导的分发，需改用 Apple Developer ID 证书签名并公证，当前流程不含公证步骤。
